📘 Documentation Bizpilote Flex

Bizpilote Flex est un framework CSS Utility‑First 100% Flexbox, moderne, rapide, minimaliste et extensible. Il inclut un système de thèmes, des utilitaires flex, grid, spacing, typographie, couleurs, images, animations, composants et responsive universel.

📦 Installation

Ajoutez simplement le fichier CSS :

<link rel="stylesheet" href="bizpilote-flex.min.css">

🎨 Thèmes

Bizpilote Flex inclut 5 thèmes :

  • Dark
  • Light
  • Neon
  • Warm
  • Custom

Changer de thème :

<html data-theme="neon">
