# Bizpilote Flex

Framework **utility‑first** basé à 100% sur **Flexbox**, conçu pour créer des interfaces modernes, rapides, responsives et thématisables.  
Inspiré de Tailwind, mais optimisé pour la simplicité, la vitesse et la lisibilité.

![Bizpilote Flex Logo](logo.svg)

---

## 🚀 Fonctionnalités

- 100% Flexbox (pas de Grid)
- Utility‑first (classes simples, rapides, lisibles)
- Responsive universel (XS → XXL → 8K)
- Multi‑thèmes (Dark, Light, Neon, Warm, Custom)
- Auto‑theme jour/nuit
- Navigation responsive smartphone/tablette/desktop
- Cards, Buttons, Layouts, Pricing, Hero, Dashboard
- Playground interactif
- Compatible CDN + NPM
