Documentation officielle Bizpilote Flex

Bizpilote Flex est un framework utility‑first basé à 100% sur Flexbox, conçu pour créer des interfaces modernes, rapides, responsives et thématisables.

Installation

Ajoute simplement le fichier CSS dans ton projet :

<link rel="stylesheet" href="bizpilote-flex.css">

Et ton fichier JavaScript :

<script src="script.js"></script>

Philosophie

  • Utility-first
  • 100% Flexbox
  • Responsive universel
  • Thèmes dynamiques
  • Auto‑theme jour/nuit
  • Compatible tous écrans (XS → XXL → 8K)

Flexbox — Classes principales

Display

.flex { display: flex; }
.inline-flex { display: inline-flex; }

Direction

.row { flex-direction: row; }
.col { flex-direction: column; }

Alignement

.j-center { justify-content: center; }
.a-center { align-items: center; }

Gap

.gap-sm { gap: 8px; }
.gap-md { gap: 16px; }
.gap-lg { gap: 32px; }

Flex basis

.basis-1-3 { flex-basis: 33.333%; }
.basis-1-2 { flex-basis: 50%; }
.basis-full { flex-basis: 100%; }

Responsive universel

Bizpilote Flex supporte tous les écrans :

  • Smartphones (XS)
  • Tablettes (SM)
  • Laptops (MD)
  • Desktop (LG)
  • Ultra‑wide (XL)
  • 4K / 8K (XXL)

Exemple

<div class="flex row md-col xl-gap">...</div>

Thèmes

Bizpilote Flex inclut plusieurs thèmes :

  • Dark
  • Light
  • Neon
  • Warm
  • Custom

Changer de thème

setTheme("neon");

Auto‑theme jour/nuit

autoThemeByHour();

Exemple complet

<section class="flex row md-col gap-lg">
  <div class="card basis-1-3 sm-full">Bloc 1</div>
  <div class="card basis-1-3 sm-full">Bloc 2</div>
  <div class="card basis-1-3 sm-full">Bloc 3</div>
</section>
